# AI Meeting Notes Summarizer

An open-source, privacy-first corporate productivity application that automatically converts messy, lengthly meeting transcripts into concise executive summaries, key discussion logs, and trackable action items.

## 🚀 Features
* **Multi-Format Input:** Supports raw copy-pasted logs or direct plain text file (.txt) uploads.
* **Smart Categorization:** Automatically filters conversations into distinct summaries, talking milestones, and deadlines.
* **Action Item Extraction:** Tracks assignments and isolates team responsibilities cleanly.
* **Secure Local Execution:** Processes data completely offline using Ollama to safeguard internal corporate conversations.

## 🛠️ Infrastructure Build
* **Interface Module:** Streamlit
* **AI Processing Orchestrator:** LangChain & Ollama (Llama 3 engine)
